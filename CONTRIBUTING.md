# Contributing to Oddly

Thank you for your interest in contributing to Oddly!

Oddly is an open-source project built around spontaneous thinking, speaking, discussion, and exploration. Contributions of all kinds are welcome, whether you're fixing a bug, improving the interface, adding topics, improving accessibility, or proposing a new feature.

## 🧭 Ways to Contribute

There are several ways you can contribute:

- Add new topics
- Improve existing topics
- Fix bugs
- Improve the user interface
- Improve responsive behavior
- Improve accessibility
- Improve performance
- Add automated tests
- Improve documentation
- Suggest new features
- Create new practice modes
- Review pull requests
- Report issues

You don't need to make large changes to contribute. Small improvements are valuable too.
