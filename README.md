# Oddly

> Think less. Speak more. Get a topic. Go.

Oddly is a minimal, interactive topic generator designed for practicing spontaneous thinking, speaking, discussion, and exploration.

Choose a category and difficulty, spin for a topic, and challenge yourself to respond without extensive preparation. Oddly also includes timed practice, topic history, sound feedback, and a separate Deep Research mode for more substantial discussion topics.

## ✨ Features

- 🎲 **Random Topic Generation**
  - Generate a new topic with a single click.
  - Topics are selected based on category, difficulty, and recent topic history.

- 🧠 **Two Practice Modes**
  - **Off the Cuff** — quick prompts designed for spontaneous thinking and speaking.
  - **Deep Research** — more substantial topics intended for deeper exploration.

- 📚 **Five Topic Categories**
  - Politics
  - History
  - Financial
  - AI Technology
  - Education

- 🎚️ **Difficulty Levels**
  - Easy
  - Medium
  - Hard

- ⏱️ **Built-in Timer**
  - Practice responding to a topic within a defined time limit.
  - Configurable durations from 1 to 10 minutes.

- 📖 **Topic History**
  - Keeps track of previously generated topics.
  - Separate history is maintained for Off the Cuff and Deep Research modes.

- 🔥 **Streak Tracking**
  - Tracks your current practice streak within the application.

- 🔊 **Sound Feedback**
  - Optional sounds for spins, timer events, and completion.
  - Sound can be enabled or disabled from the interface.

- 🎨 **Interactive Interface**
  - Dark atmospheric interface.
  - Category-specific illustrations.
  - Animated transitions.
  - Interactive flashlight/torch effect revealing hidden topics.

- 📱 **Responsive Design**
  - Designed to work across desktop and smaller screens.

## 🎯 Why Oddly?

It is easy to prepare when you have unlimited time.

It is much harder to think clearly when a topic is presented to you unexpectedly.

Oddly is built around that constraint.

The goal is simple: **give yourself a topic, give yourself a limited amount of time, and see what you can come up with.**

This can be useful for:

- Public speaking practice
- Interview preparation
- Debate and discussion practice
- Communication training
- Impromptu speaking
- Critical thinking exercises
- Learning through self-directed exploration

## 🛠️ Built With

Oddly is intentionally lightweight and currently uses standard web technologies:

- HTML5
- CSS3
- Vanilla JavaScript
- SVG
- Browser Audio APIs / embedded audio
- No frontend framework required

The application is structured around separate HTML, CSS, and JavaScript files, making it easy to inspect, modify, and contribute to.
